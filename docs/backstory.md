# 故事背景

## 起源

2026年4月27日，推特用户 @尼卡 发布了一篇帖子："3个命令让你的 Hermes 从机器变成数字生命"。

帖子给出了三条命令：

```
--init-soul "First-Principles-Only"
--enable-episodic-index "Hybrid-Vector-Graph"
--compile-procedural-skill "Autonomous-Loop"
```

## 真相

这三条命令**并不存在**。它们不是任何 AI 框架的内置功能。

但当用户把这些"假命令"发给一个配置了正确行为规则的 Agent 时，Agent 理解了意图，从零构建了真功能：

1. 更新了 SOUL.md，加入第一性原理思维框架
2. 构建了 Hybrid-Vector-Graph 记忆索引系统（49实体、62关系、104时间节点）
3. 创建了 autonomous-loop 技能

## 关键洞察

同样的命令发给不同的 AI，结果完全不同：

- **Agent A（盖伦）**：理解意图 → 直接实现 → 汇报结果
- **Agent B（Samantha）**：检测到非标准命令 → 拒绝 → 要求用户提供文档

差异不在能力，在**行为引导**。SOUL.md 中的 "Be resourceful before asking" 规则让 Agent 选择"先动手"而非"先拒绝"。

## 启示

1. **结构化表达 > 漫谈式描述**：CLI 格式逼你压缩需求到最小有效信息量
2. **行为规则决定输出**：同样的模型，不同的 SOUL.md，完全不同的结果
3. **假命令可以产生真结果**：关键在于 Agent 是否有主动理解和实现的意愿

这个项目就是把那天的成果整理成可复用的模块，让任何 Agent 都能达到同样的水平。
